# تطبيق الأكاديمية العربية (Android · Flutter)

تطبيق Android بالعربية والإنجليزية، يعمل مع نفس الخادم وقاعدة البيانات التي يستخدمها موقعك. أي تسجيل من التطبيق يظهر في لوحة الإدارة على الموقع، والعكس صحيح.

## ما في التطبيق

**للزوار**
- الرئيسية: افتتاحية متحركة، وعدّاد للأرقام، ودائرة المسارات بإبرة نحاسية تتحرك نحو المسار المختار، وبرامج مميزة، وخطوات الالتحاق.
- البرامج: بحث يفهم العربية (ايزو = ISO)، وتصفية بالمسار والمستوى، وبطاقات تظهر بالتتابع.
- صفحة البرنامج: انتقال ناعم للعنوان، والمخرجات، ونموذج تسجيل تظهر بعده علامة صح متحركة ورقم مرجعي.
- التحقق من الشهادات برمز التحقق.
- تواصل معنا: اتصال، واتساب، الخريطة، ونموذج رسالة.
- طلب تدريب للمؤسسات.
- تبديل اللغة (عربي / English) والمظهر (فاتح / داكن / تلقائي).

**للإدارة** (من «المزيد» ثم «دخول الإدارة»، بنفس بريد وكلمة مرور لوحة الموقع)
- نظرة عامة: أرقام اليوم، رسم بياني لآخر 30 يوماً، والبرامج الأكثر طلباً.
- التسجيلات: بحث، وتصفية بالحالة، وتغيير الحالة، واتصال وواتساب مباشر، وملاحظات، وإصدار شهادة، وحذف.
- الرسائل وطلبات المؤسسات والشهادات.
- البرامج: نشر أو إخفاء أي برنامج.
- الحساب: تغيير كلمة المرور وتسجيل الخروج.

**مهم:** يجب أن يكون الخادم (Render) مربوطاً بالموقع عبر ملف `public/_redirects`، وإلا فلن تعمل النماذج ولوحة الإدارة.

## طريقة 1 (الأسهل): بناء APK على GitHub بدون تثبيت أي شيء
1. على github.com أنشئ مستودعاً جديداً باسم `arab-academy-app`.
2. اضغط **uploading an existing file**، وارفع **كل ما بداخل** هذا المجلد (ومن ضمنه المجلد المخفي `.github`). ثم اضغط **Commit changes**.
   - إن لم يظهر مجلد `.github` عند السحب: من **Add file ← Create new file** اكتب الاسم `.github/workflows/build-apk.yml` والصق محتوى الملف بنفس الاسم من هذا المجلد.
3. افتح تبويب **Actions** في المستودع. سيبدأ البناء تلقائياً، أو اضغط **Build APK ← Run workflow**.
4. بعد حوالي 10 دقائق تظهر علامة ✓ خضراء. افتح عملية البناء، ومن أسفل الصفحة في قسم **Artifacts** حمّل `arab-academy-apk`.
5. فك الضغط، وانقل `app-release.apk` إلى الهاتف وثبّته (وافق على **تثبيت التطبيقات من مصادر غير معروفة** إن طُلب منك).

## طريقة 2: البناء على جهازك
1. ثبّت **Flutter** من flutter.dev، و **Android Studio** (لتثبيت Android SDK).
2. شغّل `flutter doctor` وأصلح ما يظهر باللون الأحمر.
3. داخل مجلد المشروع:
   ```bash
   bash tool/setup_android.sh
   flutter build apk --release
   ```
4. ستجد الملف في `build/app/outputs/flutter-apk/app-release.apk`.

للتجربة على هاتف موصول بالكمبيوتر: `flutter run`.

## النشر على Google Play (لاحقاً)
الـ APK الحالي موقَّع بمفتاح تجريبي، وهذا يكفي لتثبيته وتوزيعه مباشرة. للنشر على Google Play تحتاج حساب مطوّر ومفتاح توقيع خاص بك، ثم بناء `flutter build appbundle`.

## هيكل المشروع
```
lib/
  core/      الإعدادات، الألوان والخطوط، الترجمة، الاتصال بالخادم، حالة التطبيق
  widgets/   الحركات، دائرة المسارات، بطاقة البرنامج، عناصر مشتركة
  screens/   شاشات الزوار
  screens/admin/  شاشات الإدارة
assets/      دليل البرامج (يظهر فوراً حتى قبل رد الخادم)، الشعار، أيقونة التطبيق
android_overrides/  إعدادات Android (صلاحية الإنترنت، اسم التطبيق، لون شاشة البداية)
```
